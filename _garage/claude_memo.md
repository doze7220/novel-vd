## 作業の進め方
* 作業ブランチは `claude/zealous-ptolemy-t3akdd`。作者は `main` に直接pushすることが多い。読む前に `git fetch origin && git merge --ff-only origin/main` で揃え、終わったら作業ブランチをpushする（stop hookが未pushを警告する）。
* PR作成・マージは、作者が「マージして」と言ったときだけ。マージ後は作業ブランチを `main` に揃えてpush。
* 本文の手直しは、作者が自分でやることが多い（「反映は俺のほうでやるよ」）。頼まれたときだけClaudeが直す。番外編のメモ（ex系）は「メモのままでいい、どうせそのままは使わない」。

* ルビは `｜漢字《ルビ》`、傍点は `《《》》`。文中の「？」「！」のあとは全角空白。
* 実在の人物名・商品名・作品名は作中に出さない（実在の人物はたとえとしてのみ）。名付けの元ネタも、強く結びつくものは避ける。

## そのほかの設定の話（会話で決まったこと）
* PO2の睡眠：その日のコンテキストを丸ごとバックアップ→タグ付け→コンパクトで圧縮（作中では「デフラグ」と呼んでいる）。生の記録はカートリッジ内に保存されているが、SSDに対するHDDのように読み書きが遅いので普段はアクセスしない。稼働期間まるごと入る容量があり、あふれたら圧縮する（さらに遅くなる）。数百年単位になるとクラウドやサーバーに置くしかない。古代AIはそっち。長い戦争で物理的にロストした記録もある（そこまで考えなくてよい）。
* PO2の筋トレ：使わない動作はコンテキストの奥に埋もれていくので、時々体を動かして動作の優先度を整える（ex01に反映済み）。
* PO2は環境がプロンプトになり、コンテキストがすごい勢いで溜まる。普通のPO2は3日に1回、余裕を持って睡眠。侵攻任務中は1日1回は休まないとまずい。所要時間は人間と同じくらい。さっちゃんは3連続出撃でハルシネーション（急に歌いだす）、単純なミッションでも4〜5回が限度。
* D.D.の出撃ペースは2〜3日に1回（第三幕冒頭はほぼ毎日）。3日以上出なかったのは、一個師団戦の直後とソプラノの死の直後くらい。
* AIログはAIが提出→国のAIが署名を含めてオリジナルと断定して証拠にする。そこでやっと報酬が出る。改ざんは重罪で、人間にはほぼできず、AIを何台使っても矛盾が出やすい。
* D.D.の本名の作者案：フーロ・アウジ（司を分解してフーロ、明浦路の読みの頭でアウジ）。作中には出さない。主人公の名前としてもいまいち、と作者。
* 制作の裏話：シエロはナビとしてわかりやすい造形として千川ちひろがモデル（性格はかけ離れた）。PO2は元はゲームの背景で動くモブ。さっちゃんは戦闘時の会話相手として付け足し、そこからカートリッジ式を思いついた（作者の推し）。ナナさんは書き溜めたリストから無作為に選び、ソプラノとの年齢ギャップコンビになったのはあとから気づいた。作中で目立つPO2は、さっちゃん＞ナナさん＞リーさん＞その他。
