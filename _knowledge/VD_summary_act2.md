# 14話時点サマリー：無職になったギャンブルレーサーが、銀河で『流浪の悪魔』と呼ばれるようになるまで

**キャッチコピー：** 飛ぶのが好きなだけの男と、赤字を許さない女。たった二人の銀河戦記。
**タグ：** スペースオペラ / バディ / 戦記 / 傭兵 / ドッグファイト / AI・ロボット

本作は、後に「流浪の悪魔」と呼ばれることになるD.D.の前半生を描く物語。

---

# 1. 主要キャラクター

### D.D.（主人公 / 『人形遣い』）
元ギャンブルレーサー。勝敗や名声には執着せず、飛ぶこと以外に自分の価値を見いだせず、それだけを生きがいとしている。
空間把握能力・運動予測・操縦技術においてAIすら凌駕する異常な才能を持ち、戦場では被弾ゼロ・敵撃破という最適解を直感的に導き出す。AIが敵弾を検知してから最適解を計算するのに対し、D.D.は戦場全体の流れから未来の危険を直感的に予測して身体が先に動く。
黒騎士との戦闘映像が拡散され「人形遣い（DOLL MASTER）」の異名が広まりつつある。有人機撃墜には今なお葛藤を抱いており、可能ならば撃墜を避けたいと考えている。しかし飛ぶため、仲間を守るために必要なら引き金を引く覚悟を決めている。
ソプラノの帰還を巡ってはCCC正規軍「クルセイダー」6機を相手に、被弾ゼロ・武装破壊のみで全機を無力化するという離れ業をやってのけた。
その後、G.G.との模擬戦（クラウドシミュレーション）にて、圧倒的な装甲・火力・多彩な武装を誇る「グラットン・グラビティ」を相手に、最終盤で唯一の隙を突いて撃破に成功。G.G.本人に「先代・人形遣いを超えている」と評されるほどの機動を見せた。
この模擬戦の結果、G.G.から「500億クレジットを稼げばダンシング・ドールを正式に譲る」という条件を提示され、達成を目指すことになった。年齢24歳。

### シエロ・ルマスター
D.D.の専属オペレーター。年齢23歳。リフト・ユニオン創設家系「ルマスター家」の一員（G.G.は入り婿の祖父）。
理知的で現実主義なキャリアウーマン。「赤字を許さない」が信条。D.D.の才能を最も深く理解し支える存在。冷静な判断力と指揮能力でセッティを支える。
セッティを「ホームポイント」と考え、仲間が帰ってくる場所を守ることを自らの使命としている。
ソプラノに対しては当初厄介者扱いし、価値観の違いから大喧嘩もするが、やがて奇妙な絆を結ぶ。ソプラノの帰還段取りではG.G.の権限を無断で借用するなど、規格外の行動力も見せる。ソプラノ帰還後も、暗号通信を使った秘密の文通を続けている。
D.D.との契約から1年が経過し、専属オペレーター契約の任期満了を迎えるが、D.D.本人の強い希望により続投を承諾。本部への継続打診を行うことになった。業務上の理由で胸にさらしを巻いている。

### ソプラノ（本名：ミース・クラヴェル、正体：CCCの聖女）
宗教国家CCCからやってきた少女。外見は14、5歳に見えるが、実は25歳でセッティの最年長。
漂流中をD.D.に救われセッティに居候する。「人殺しは絶対に良くない」という強い平和主義を持ち、傭兵の在り方を巡ってシエロと衝突するが、やがて奇妙な絆を育む。
セッティが襲撃された夜、平和への祈りだけでは目の前の命を守れない現実を知り、「CCCのミース・クラヴェル」として自分の立場で戦うことを決意。母国への帰還を選び、セッティを去った。
帰還後、ニュース映像により、彼女の正体が「病気療養中」とされていたCCCの象徴的存在＝聖女ミース・クラヴェルであったことが判明し、D.D.たちを驚愕させた。
現在はセッティを離れているが、シエロとの間で暗号通信を使った秘密の文通が続いている（D.D.との有人機撃墜を巡る対立は、平行線のまま解決はしていない）。

### G.G.
伝説の傭兵「暴食の重力」。リフト・ユニオン役員。D.D.の才能を見出しスカウトした恩人。シエロの祖父。
ソプラノの帰還段取りにおいては、本人の与り知らぬところで自身の権限をシエロに借用された。
その後、噂を聞きつけてセッティに突撃訪問し、D.D.に模擬戦を挑む。表向きは「二つ名で浮かれるな」という説教目的だが、実際はD.D.と戦いたかっただけだとシエロに見抜かれている。模擬戦では愛機「グラットン・グラビティ」の全火力（重力崩壊弾含む）を投入するも、最終的にD.D.に撃破され敗北。D.D.の実力を高く評価し、「500億クレジットを稼げばダンシング・ドールを正式に譲る」という条件を提示した。

### さっちゃん（PO2-SK140）
ダンシング・ドールの戦術支援AI。D.D.の異常な操縦に悲鳴を上げながらもサポートを続ける。クルセイダー戦では「武装破壊優先・撃墜回避」というリスクの高い指示にも、抗議しつつ最終的には従った。G.G.との模擬戦でも、絶望的な戦況の中でD.D.と共に最後まで戦闘継続を選んだ。

### PO2
セッティを支える小型作業ロボット。整備・操船・消火・生活支援まで幅広く担当し、D.D.たちにとっては家族同然の存在。いずれも個性豊かで、シエロ直筆の色別マークが描かれている。セッティに102体所属しており、それぞれが固有の役割と個性を持つ。
特にナナさんはソプラノと強い絆を育み、別れ際にお揃いのウサギのキーホルダーを贈られた。リーさんはソプラノの正体調査を何度もやり直す羽目になり苦労した。

### 黒騎士（V.S.）
バルバロス覇権機構（BH）のエースパイロット。冷酷だが、D.D.を強敵と認めている。

### CCCクルセイダー（C4）
CCCの正規軍。撤退や被弾を恐れず死をも厭わない特攻的な戦法を取る、狂信的な部隊。ソプラノの引き渡しを阻もうと立ちはだかるが、D.D.に武装だけを破壊され全機無力化、撃墜されることなく退いた。

# 2. メカニック・組織

### ダンシング・ドール
D.D.に貸与された白銀の戦闘機。ピーキーな性能だが、D.D.だけが限界を引き出せる。現在はリフト・ユニオン（G.G.）の所有物だが、D.D.が500億クレジットを稼げば正式に譲渡される見込み。

### グラットン・グラビティ（G.G.機）
G.G.の愛機。長距離侵攻戦闘機で、ダンシング・ドールの約2倍の全長を誇る大型機。パワーバルカン、スプレーランチャー、追尾式フィールドトルピード、マルチカノンなど多彩な武装に加え、疑似ブラックホールを発生させる最終兵器「グラットン・グラビティ・カノン」を搭載する。防御力・火力ともに圧倒的だが、旋回性能・小回りに劣る。

### アンカー・ガレージ『セッティ』
D.D.たちの生活拠点兼小型母艦。シエロと多数のPO2（ミーさん、ナナさん、ユーさん、リーさんなど）が運営している。
賞金稼ぎに襲撃された際は、シエロの指揮とPO2たちの決死のダメージコントロールにより、D.D.が帰還するまで持ち堪え、ソプラノにとっても温かい「家」となった。その後の損傷は、リフト・ユニオン本部のドックで修理された。
G.G.の来訪時には、セッティのPO2群の演算リソースを用いたクラウドシミュレーションにより、実弾を使わない高精度な模擬戦闘も可能。

### 国家・勢力
* **リフト・ユニオン**: 独立自由傭兵支援組織。D.D.・シエロ・G.G.が所属する。数ある傭兵支援組織の一つ。
* **アセット・バンク・ファンド（ABF）**: D.D.たちのいる国家。
* **バルバロス覇権機構（BH）**: 黒騎士が所属する国家。
* **センター・カテドラル・クワイア（CCC）**: 宗教国家。ソプラノ（聖女ミース・クラヴェル）の故郷。正規軍として「クルセイダー」を擁する。

* **傭兵** 国家から依頼を受け、各戦域で任務を遂行する独立戦力。所属は支援組織・独立個人など多種多様ではあるが、いずれも正規軍ではなく、報酬によって活動する。

# 3. これまでのストーリー（14話時点）

## 【第一幕】傭兵への転身と才能の開花
万年最下位のギャンブルレーサーだったD.D.は、伝説の傭兵G.G.に才能を見出されリフト・ユニオンの傭兵となる。
オペレーターのシエロ、戦術AIのさっちゃんと共に初陣を無傷で飾り、AIを凌駕する超常的な空間把握・運動予測能力を発揮し始める。
BHのエース「黒騎士」との激闘を経て、その戦闘映像が拡散。D.D.は「人形遣い」として銀河に名を知られ始める。
レース競技では弱点だった能力が戦場でこそ輝くことに気づき、D.D.は飛ぶ才能を生かせる居場所として戦場を受け入れる。

## 【第二幕：ホームとアンカー（09〜14話）】
CCC戦域付近で、D.D.たちは漂流する民間シャトルから「ソプラノ」と名乗る少女を救助する。
教会の温室育ちの彼女は、D.D.が有人機を撃墜したことにショックを受け「人殺しは良くない」と傭兵を否定。シエロと激しく衝突し取っ組み合いの大喧嘩に発展するが、やがて互いの立場の違いを認め合い、不器用な絆を育む。

そんな折、D.D.の出撃中にセッティがBHの賞金稼ぎたちに急襲される。通信が遮断され絶体絶命の中、シエロの指揮とPO2たちの決死の消火・修復作業により、セッティはD.D.の帰還まで持ち堪える。怒りに燃えるD.D.が賞金稼ぎを瞬く間に殲滅し、仲間たちは無事生還を果たす。
ブリッジで無力感に打ちひしがれていたソプラノは、シエロたちが必死に守り抜いた「家」の温かさを知り、自身の平和への祈りが現実の危機には無力であることを悟る。その夜、戦争を否定する信念を曲げないまま、自身の立場で戦うことを決意し、暗闇の中で自らの真の名「CCCのミース・クラヴェル」を静かに口にする。

セッティの修理期間を経て、ソプラノは唐突にD.D.とシエロへ帰郷の決意を告げる。シエロはG.G.の権限を無断借用し、CCCとの極秘通信ルートを確保。中立のデブリ帯での引き渡しが計画される。
セッティでの最後の夜、ソプラノはPO2一体ずつに別れを告げ、ナナさんとお揃いのキーホルダーを交換、シエロ特製のアップルパイを囲む食卓で涙を零す。
翌朝の引き渡し直前、CCC正規軍「クルセイダー」6機が接近。死を恐れぬ狂信的な戦法にD.D.も戦慄しつつ、あえて「撃墜せず武装のみ破壊する」という高リスクな戦術を選択し、さっちゃんの抗議を押し切って被弾ゼロで全機を無力化、誰も殺すことなく撃退する。
無事に引き渡しポイントに到着したソプラノは、「セッティが自分にとっての『ホームポイント』だった」と語りつつも、これから帰る故郷を自らの意志で戦う「戦場」と定め、振り返らずに輸送船へと消えていった。

後日、セッティのキャビンに流れたニュース映像で、「病気療養中」とされていたCCCの象徴・聖女ミース・クラヴェルの復帰が報じられる。それは紛れもなく、彼らが見送った「ソプラノ」その人だった。D.D.とシエロは驚愕し、PO2たちも大騒ぎとなる。

日常が戻った後、ソプラノからシエロ宛に秘密のメールが届き、暗号通信を使った文通が始まる。
そこへG.G.が突然来訪し、D.D.に模擬戦を挑む。シエロには「二つ名で浮かれるな」という名目だが、実際はG.G.自身が戦いたかっただけだと見抜かれている。
クラウドシミュレーションによる模擬戦は、圧倒的な装甲・火力を誇るグラットン・グラビティにD.D.が終始追い詰められる展開となるが、最終盤、疑似ブラックホールを発生させる最終兵器「グラットン・グラビティ・カノン」の砲口という唯一の隙をD.D.が射抜き、辛勝する。G.G.はD.D.の機動を「先代・人形遣いを超えている」と高く評価。
その場でG.G.は「500億クレジットを稼げばダンシング・ドールを正式に譲る」という条件を提示し、D.D.はこれを新たな目標として受け入れる。
さらにシエロとD.D.の専属オペレーター契約が1年の満了を迎えるが、D.D.の強い希望でシエロは続投を承諾。第二幕は「第二幕『ホームとアンカー』完」として幕を閉じた。

# 4. D.D.の能力（AI評価用コンテキスト）
D.D.の戦闘能力は以下の三要素から成り立つ。
* 極めて高度な3次元空間認識能力
* 慣性まで含めた異常な運動予測能力
* 思考した軌道を即座に操縦へ反映する操作能力

これにより、AIが弾道を検知する前から回避を開始し、被弾しない軌道を直感的に選択できる。
最適解が常に変わり続ける戦場では最大の武器となるが、その存在が広まるにつれ、母艦（セッティ）を狙われるという傭兵としてのリスクも引き寄せるようになっている。
ソプラノ編終盤では、この能力の応用として「敵の武装のみを正確に撃ち抜き、撃墜せずに無力化する」という、通常の戦術AIでは推奨されない高難度の選択も成立させている。
G.G.との模擬戦では、圧倒的な火力・防御力差を機動と観察眼のみで覆し、一瞬だけ生じたシールドの隙を正確に射抜くという、瞬発的な判断力の高さも示した。

# 5. 現在のテーマ（14話時点）
「飛ぶことしかできない男」が居場所を見つけ、その居場所を守る物語から、守った相手を「送り出す」物語へ。出会いと同じくらい、別れにも真摯に向き合う姿勢が描かれる。
また、ソプラノの正体判明によって、彼女個人の内面の物語が、CCCという国家・宗教組織全体を巻き込むより大きな物語への布石となったことも示唆される。
異なる正義・信念・価値観を持つ者たちが、それらを捨てることなく互いを理解し、共に歩もうとする――というテーマは、ソプラノが去った後もD.D.とシエロの物語の核として残り続けている。
第二幕終盤では、G.G.との模擬戦を通じてD.D.自身の成長（先代を超える機動）が示されるとともに、「500億クレジットでダンシング・ドールを正式に得る」という具体的な目標が新たに提示され、D.D.とシエロの関係もオペレーター契約の継続という形で新章へ進む土台が整えられた。
