# 11話時点サマリー：無職になったギャンブルレーサーが、銀河で『流浪の悪魔』と呼ばれるようになるまで

**キャッチコピー：** 飛ぶのが好きなだけの男と、赤字を許さない女。たった二人の銀河戦記。
**タグ：** スペースオペラ / バディ / 戦記 / 傭兵 / ドッグファイト / AI・ロボット

本作は、後に「流浪の悪魔」と呼ばれることになるD.D.の前半生を描く物語。

---

# 1. 主要キャラクター

### D.D.（主人公 / 『人形遣い』）
元ギャンブルレーサー。勝敗や名声には執着せず、飛ぶこと以外に自分の価値を見いだせず、それだけを生きがいとしている。
空間把握能力・運動予測・操縦技術においてAIすら凌駕する異常な才能を持ち、戦場では被弾ゼロ・敵撃破という最適解を直感的に導き出す。AIが敵弾を検知してから最適解を計算するのに対し、D.D.は戦場全体の流れから未来の危険を直感的に予測して身体が先に動く。
黒騎士との戦闘映像が拡散され「人形遣い（DOLL MASTER）」の異名が広まりつつある。有人機撃墜には今なお葛藤を抱いており、可能ならば撃墜を避けたいと考えている。しかし飛ぶため、仲間を守るために必要なら引き金を引く覚悟を決めている。年齢24歳。

### シエロ・ルマスター
D.D.の専属オペレーター。年齢23歳。
理知的で現実主義なキャリアウーマン。「赤字を許さない」が信条。D.D.の才能を最も深く理解し支える存在。冷静な判断力と指揮能力でセッティを支える。
セッティを「ホーム・ポイント」と考え、仲間が帰ってくる場所を守ることを自らの使命としている。
ソプラノに対しては当初厄介者扱いし、価値観の違いから大喧嘩もするが、やがて奇妙な絆を結ぶ。業務上の理由で胸にさらしを巻いている。

### ソプラノ（本名：ミース・クラヴェル） 【NEW】
宗教国家CCCからやってきた少女。外見は14、5歳に見えるが、実は25歳でセッティの最年長。
漂流中をD.D.に救われセッティに居候する。「人殺しは絶対に良くない」という強い平和主義を持ち、傭兵の在り方を巡ってシエロと衝突する。しかし、平和への願いだけでは目の前の命を守れない現実を知る。賞金稼ぎ襲撃時にシエロやPO2たちが命懸けで「家（セッティ）」を守る姿に心を打たれ、戦争を否定する信念はそのままに、「CCCのミース・クラヴェル」として自分の立場で戦うことを決意する。

### G.G.
伝説の傭兵「暴食の重力」。リフト・ユニオン役員。D.D.の才能を見出しスカウトした恩人。

### さっちゃん（PO2-SK140）
ダンシング・ドールの戦術支援AI。D.D.の異常な操縦に悲鳴を上げながらもサポートを続ける。

### PO2
セッティを支える小型作業ロボット。整備・操船・消火・生活支援まで幅広く担当し、D.D.たちにとっては家族同然の存在。いずれも個性豊かで、シエロ直筆の色別マークが描かれている。セッティに102体所属しており、それぞれが固有の役割と個性を持つ。

### 黒騎士（V.S.）
バルバロス覇権機構（BH）のエースパイロット。冷酷だが、D.D.を強敵と認めている。

---

# 2. メカニック・組織

### ダンシング・ドール
D.D.に貸与された白銀の戦闘機。ピーキーな性能だが、D.D.だけが限界を引き出せる。

### アンカー・ガレージ『セッティ』
D.D.たちの生活拠点兼小型母艦。シエロと多数のPO2（ミーさん、ナナさん、ユーさん、リーさんなど）が運営している。
賞金稼ぎに襲撃された際は、シエロの指揮とPO2たちの決死のダメージコントロールにより、D.D.が帰還するまで持ち堪え、ソプラノにとっても温かい「家」となった。

### 国家・勢力
* **リフト・ユニオン**: 独立自由傭兵支援組織。D.D.・シエロ・G.G.が所属する。数ある傭兵支援組織の一つ。
* **アセット・バンク・ファンド（ABF）**: D.D.たちのいる国家。
* **バルバロス覇権機構（BH）**: 黒騎士が所属する国家。
* **センター・カテドラル・クワイア（CCC）**: 宗教国家。ソプラノの故郷。

* **傭兵** 国家から依頼を受け、各戦域で任務を遂行する独立戦力。所属は支援組織・独立個人など多種多様ではあるが、いずれも正規軍ではなく、報酬によって活動する。

# 3. これまでのストーリー（11話時点）

## 【第一幕】傭兵への転身と才能の開花
万年最下位のギャンブルレーサーだったD.D.は、伝説の傭兵G.G.に才能を見出されリフト・ユニオンの傭兵となる。
オペレーターのシエロ、戦術AIのさっちゃんと共に初陣を無傷で飾り、AIを凌駕する超常的な空間把握・運動予測能力を発揮し始める。
BHのエース「黒騎士」との激闘を経て、その戦闘映像が拡散。D.D.は「人形遣い」として銀河に名を知られ始める。
レース競技では弱点だった能力が戦場でこそ輝くことに気づき、D.D.は飛ぶ才能を生かせる居場所として戦場を受け入れる。

## 【09〜11話】ソプラノとの出会いと「家」の防衛
CCC戦域付近で、D.D.たちは漂流する民間シャトルから「ソプラノ」と名乗る少女を救助する。
教会の温室育ちの彼女は、D.D.が有人機を撃墜したことにショックを受け「人殺しは良くない」と傭兵を否定。シエロと激しく衝突し取っ組み合いの大喧嘩に発展するが、やがて互いの立場の違いを認め合い、不器用な絆を育む。

そんな折、D.D.の出撃中にセッティがBHの賞金稼ぎたちに急襲される。「人形遣い」の母艦を潰す狙いだった。
通信が遮断され絶体絶命の中、シエロの指揮とPO2たちの決死の消火・修復作業により、セッティはD.D.の帰還まで持ち堪える。怒りに燃えるD.D.が賞金稼ぎを瞬く間に殲滅し、仲間たちは無事生還を果たす。

ブリッジで無力感に打ちひしがれていたソプラノは、シエロたちが必死に守り抜いた「家」の温かさを知り、自身の平和への祈りが現実の危機には無力であることを悟る。
その夜、ソプラノは戦争を否定する信念を曲げず、それでも逃げることなく自身の立場で戦うことを決意。暗闇の中で自らの真の名、「CCCのミース・クラヴェル」を静かに口にするのだった。

# 4. D.D.の能力（AI評価用コンテキスト）
D.D.の戦闘能力は以下の三要素から成り立つ。
* 極めて高度な3次元空間認識能力
* 慣性まで含めた異常な運動予測能力
* 思考した軌道を即座に操縦へ反映する操作能力

これにより、AIが弾道を検知する前から回避を開始し、被弾しない軌道を直感的に選択できる。
最適解が常に変わり続ける戦場では最大の武器となるが、その存在が広まるにつれ、今回のように「母艦（セッティ）を狙われる」という傭兵としてのリスクも引き寄せるようになっている。

# 5. 現在のテーマ（11話時点）
「飛ぶことしかできない男」が居場所を見つけ、その居場所を守る物語へ発展。同時に、異なる正義・信念・価値観を持つ者たちが、それらを捨てることなく互いを理解し、共に歩もうとする物語。
