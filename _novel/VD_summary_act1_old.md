# 第一幕サマリー：無職になったギャンブルレーサーが、銀河で『流浪の悪魔』と呼ばれるようになるまで

**キャッチコピー：** 飛ぶのが好きなだけの男と、赤字を許さない女。たった二人の銀河戦記。
**タグ：** スペースオペラ / バディ / 戦記 / 傭兵 / ドッグファイト / AI・ロボット

## 1. 主要キャラクター
* **D.D.（主人公 / 後の『流浪の悪魔』『人形遣い』）**
  元ギャンブルレーサー。「飛ぶこと」以外何もできない男。レースでは万年最下位だったが、空間把握能力と運動予測においてAIすら凌駕する異常な才能（未来予知レベル）を持つ。戦場では最適解（被弾ゼロで敵を撃つ）を直感で弾き出し、神がかった機動を見せる。
* **シエロ・ルマスター**
  D.D.のサポートオペレーター。理知的で赤字を許さないキャリアウーマン。最初はD.D.を疑っていたが、彼の才能と人間性に触れ、次第に良きバディとなっていく。
* **G.G.**
  伝説の傭兵「暴食の重力」にしてリフト・ユニオン役員。D.D.の才能を見抜き傭兵にスカウトした張本人。豪快な性格。
* **さっちゃん（PO2-SK140）**
  D.D.の愛機「ダンシング・ドール」の管制・戦術補助AI。D.D.の常識外れの機動に演算が追いつかず、いつも悲鳴を上げている。D.D.に懐いている。
* **黒騎士（V.S.）**
  バルバロス覇権機構（BH）のエース。黒い機体を操る凄腕で、戦場にいる者は民間人だろうと容赦なく狩る冷酷さを持つ。

## 2. メカニック・用語
* **ダンシング・ドール：** D.D.が搭乗する白銀の戦闘機。ピーキーな性能だがD.D.の操作で舞うような機動を見せる。
* **アンカー・ガレージ『セッティ』：** D.D.たちの拠点となる小型母艦。多数のPO2（汎用作業ロボット）が稼働している。
* **リフト・ユニオン：** 独立自由傭兵支援組織。D.D.やシエロが所属している。

## 3. ストーリー軌跡（第一幕）
* **【起】傭兵としての目覚め**
  万年ビリのレーサーだった主人公は無職となり途方に暮れていたところを、伝説の傭兵G.G.にスカウトされる。適性試験で操船や戦術の座学は平凡だったが、実機演習では驚異的な回避・射撃センスを見せ「SS」評価を獲得。「D.D.」というコールサインを与えられる。
* **【承】初陣と才能の片鱗**
  オペレーターのシエロ、補助AIのさっちゃんと共に初陣へ。無人機56機という過酷な状況を遊び感覚で無傷殲滅する。そのログを見たシエロたちは、D.D.の異常な空間把握と未来予測に近い機動能力に驚愕する。順調にミッションをこなす中、D.D.は初めて「有人機」を撃墜してしまう。罪悪感のなさに戸惑う彼だったが、G.G.の助言を受け「ただ飛ぶため」に戦場を駆け抜ける覚悟を決める。
* **【転】黒騎士との死闘**
  味方無人機との防衛ミッション中、BHの凄腕エース「黒騎士」と遭遇する。黒騎士は非武装の民間報道船を平然と撃墜。激怒したD.D.は、母艦セッティを狙う黒騎士の前に立ちはだかり、機体の限界を引き出す神がかった回避機動で時間を稼ぎ、ついに黒騎士を撤退させる。
* **【結】『人形遣い』の誕生**
  報道船が撮影した黒騎士戦の映像が銀河中に拡散され、D.D.は「人形遣い（DOLL MASTER）」と呼ばれるようになる。休暇中、D.D.は昔のツテでレースの代走に出場するが結果はやはり最下位。シエロは「他者と絶対に接触しない軌道」を選ぶ彼の才能が、レース（最適解が一つ）ではなく、常に状況が変化する戦場でしか輝かないことを確信する。こうして、一人の落ちこぼれレーサーの伝説が幕を開けた。

## 4. 分析：D.D.の才能について（AI評価用コンテキスト）
D.D.の強さの本質は「完璧な3次元空間認識」「慣性を含めた異常な運動予測」「それを即座に機体に反映させる操作技術」にある。彼は弾道を検知する0.4秒前に回避を開始しており、事実上の未来予知を行っている。
しかし、この能力は「他者との接触を極限まで避ける」という形で発現するため、レースではインコースに飛び込めず最下位となる。つまり彼の才能は「殺し合いの戦場」という最もカオスな環境でしか機能しないという、皮肉で特異な性質を持っている。
