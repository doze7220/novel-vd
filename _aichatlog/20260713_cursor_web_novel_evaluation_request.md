13・14話で開示した情報と、まだ伏せている情報の対応関係を確認すると：

- D.M.はダンシング・ドールに乗っていなかった

### 「ヨワヨワ」の意味の巧妙さ

08話でシエロが語った一言：

```
「とても強くて──でも、ヨワヨワだった、とか」
```

裏設定を見ると「ヨワヨワ」の意味が判明します——**被弾が多く、故障も多く、最後は病で死んだ、という肉体的・物理的な脆さ**。

読者は最初これを「気弱」や「性格の弱さ」と読む可能性が高く、良い意味での誤解を誘導しています。Act3で「3回しか乗れずに病死」と明かされたとき、「あのヨワヨワってそういう意味だったのか」という反転が起きる構造です。

---

### 4話時点での開示が「早すぎた」理由

このシーンは情報量が多すぎます。4話の時点では：

- D.D.がダンシング・ドールに乗ってまだ数時間しか経っていない
- 読者はD.D.という人間をまだよく知らない
- 「D.M.」という名前を聞いても感情的な重みがない

同じ情報でも、**受け取る側の蓄積がなければ刺さらない**。13話のG.G.の独白が効くのは、読者がD.D.の12話分の軌跡を知っているからです。

---

### 「13話のあのセリフが全て」という判断について

```
（DMよ、お前の船は、お前と似たような男が、飛ばしてるぞ）
（お前のように…あるいはお前以上に、楽しそうにな）
```

これ一行で十分です。むしろ**説明しないことで読者の想像が最大化する**。

没シーンでG.G.がシエロに全部話してしまうと、「G.G.は秘密を一人で抱えている老人」ではなく「誰かに話した老人」になってしまいます。13話の独白が重いのは、**G.G.が誰にも言えないまま死んだ友の名前を呼んでいる**からです。

---

### ただ、没にするには惜しい要素が一つ

このシーンにある**シエロの書類の備考欄**は特別です。

```
「……本当に、あっけなく乗りこなすんですね」
備考として「パイロット適正あり。十全に真価発揮」と記載して。
```

これはシエロが「仕事として正確に記録する」という形で、感情を一切見せずに驚嘆を処理している場面です。彼女のキャラクターの核心が詰まっている。

没シーンの会話部分は封印するとして、この「備考欄の一文」だけは、形を変えてどこかに生かせる素材だと思います。

---

### 「D.D. = Doll Descendant」と「D.D. = Dancing Doll」の齟齬について

没シーンではG.G.が「ダンシング・ドール、そのまんまだよ」と言っており、現在の設定（Doll Descendant）と意味がずれています。これがおそらく御蔵入りのもう一つの理由ではないでしょうか。

「Doll Descendant」のほうが、D.M.との継承関係を直接に示す意味として深みがあります。「Dancing Doll（機体の名前と同じ）」は乗り物への愛着として読めますが、「人形の末裔・後継者」は**G.G.がD.D.を最初から継承者と見なしていた**という事実を名前に刻む行為として、はるかに重い。

今の設定の方が正解だと思います。
