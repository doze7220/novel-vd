# 第二幕「ホームとアンカー」レビュー（第9〜14話）

## 第09話「さまよいのソプラノ《Soprano flounder》」

**あらすじ**：CCC戦域からの帰還中、D.D.は漂流する個人用シャトルを発見し、乗っていた少女「ソプラノ」を保護する。素性を明かさない彼女を、D.D.はシエロの反対を押し切って居候させる。シエロはCCC上流階級の家出少女と見立ててリーさんに身元調査をさせるが、PO2の会話ログから「教会の孤児で、メッセンジャー」だと判明して調査をやり直す。さらに「子ども扱い」をきっかけにした口論から年齢の話になり、ソプラノが実は25歳で船内の最年長だと分かる。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 7.5 | ソプラノは「下手っぴ」な三つ編みや、怯えていても礼は欠かさない所作で、育ちの良さと世間知らずを同時に見せる導入になっている。PO2に「ラビちゃん」「はなちゃん」と名前を付けてあっという間に懐かれ、シエロが「ちょっと──おもしろくない」と感じる小さな嫉妬は、彼女の人間味を広げる良い描写。一方、D.D.の「いいよ」は第一幕の延長で、この話では新しい面が見えない。 |
| 世界観・設定 | 6.5 | 冒頭の数行で「三国時代」とCCCを示し、本編に入るのは手際が良い。ABF当局に引き渡せば「敵国人保護」で面倒になるという傭兵の立場の不自由さも、短く説得力がある。ただ、CCCが宗教国家であること以上の手触り（文化や訛りの具体例）がなく、シエロの推理に使われる「訛り」も中身が書かれていない。 |
| ストーリー | 6.5 | 「上流階級→教会孤児→25歳」と、シエロの見立てが三段階で外れていく構成は分かりやすく、話を貫く芯になっている。ただ外れ方が「新しいログが届いて方針を変える」の繰り返しなので、二回目は展開が読めてしまう。「メッセンジャー」「教会で拾われ」など、正体の手がかりが強すぎるのも気になる。 |
| 構成・テンポ | 6.5 | 救助→夜の調査命令→PO2に懐く→「数日後」のログ→「さらに数日後」のログ→年齢騒動→夜、と「＊＊＊」で細かく区切られ、調査の場面が三回ほぼ同じ形で続くため、中盤が間延びしている。時間経過も「さらに数日後」の後に「居候を始めて、すでに数日」と書かれていて、計算が合わない。 |
| 文章・文体 | 7.0 | シエロの心の声（「随分と、あからさまな偽名ですね」）が効いていて読みやすい。ただ、毛布を持ってくるのが整備担当のミーさんになっている（生活区画担当はユーさん）。「友旅」という造語も意味が伝わりにくい。 |
| 演出・見せ場 | 7.0 | 戦闘のない日常回として、年齢騒動のコメディがはっきりした見せ場になっている。「ピッチピチ」→「太ってる、と？？」の連続被弾や、二人がそろって「何歳だと思ってたんですか？」と迫る掛け合いはテンポが良い。オチの「全員の見立てが外れている」という三行の並べ方も気が利いている。 |
| テーマ性 | 6.0 | 「別の世界を覗きたい」少女と、それに共感するシエロという形で、居場所のテーマの種はまかれている。ただ、この話の時点では種のままで、飛ぶこと・戦争のテーマには触れていない。 |
| 引き・読後感 | 6.5 | リーさんの「今日一番、力のないPi」で締める軽い余韻は心地よい。ただ、ソプラノの正体への興味より「どうせ偉い人だろう」という予想が先に立つので、次を読ませる力はほどほど。 |
| **総合** | **6.7**（平均6.7） | |

**良かった点**
- 三人が互いの年齢を全員外していたことを三行の並列で見せるオチ。コメディとして完成度が高い。
- PO2に好かれるソプラノと、それに少しだけ嫉妬するシエロ。新キャラの魅力と既存キャラの掘り下げを一つの場面で済ませている。
- 冒頭の三国紹介ナレーションが、新しい幕の始まりを手短に告げている。

**改善提案**
- 「数日後」「さらに数日後」の調査場面を一つにまとめ、ナナさんのログで一気に「教会の孤児」まで進めると、年齢騒動に早く入れる。
- 毛布を渡すPO2をユーさんにし、「すでに数日」は「半月近く」などに直して時間を合わせる。
- 第11話で操縦を習うソプラノが、どうやって一人でシャトルに乗っていたのか（自動航行など）を一行入れておくと、後で疑問が残らない。

## 第10話「バスタイム・ダイナマイツ《Bathtime dynamites》」

**あらすじ**：ソプラノが来て一週間。シエロは、ソプラノは呼び捨てにされるのに自分は「さん付け」のままなことにもやもやする。有人機を落とした日、D.D.の告白を聞いたソプラノは「人殺しは良くない」とシエロに食ってかかり、平手打ちから取っ組み合いの大喧嘩になる。D.D.が本部に呼ばれて出ていった後、シエロとソプラノは風呂場で謝り合い、「平行線」のまま和解する。風呂上がり、バスタオル姿の二人がD.D.と鉢合わせし、シエロが投げたさっちゃんがD.D.の顔面に命中する。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 8.0 | 「間違っていないだけでは、生きていけない」と言うシエロと、「D.D.ちゃんが──苦しそう」と叫ぶソプラノ。どちらも嘘のない正論でぶつかっていて、二人の価値観が鮮やかに立つ。手を上げたあと謝らないシエロの意地と、風呂場で「大人気なかった」と反省する姿の落差も人間らしい。D.D.が「喧嘩、ダメ！！」で場を片付けてしまう抜け具合も、彼らしさとして効いている。 |
| 世界観・設定 | 6.0 | 「傷ついた傭兵を癒すのは広い湯船」という浴室の由来は楽しいが、この話で世界観が広がる部分は少ない。日常回としては妥当な配分。 |
| ストーリー | 7.5 | 呼び方へのもやもや→有人機撃墜→倫理の衝突→喧嘩→和解→ラッキースケベ、と因果がきちんとつながっている。本部の呼び出しが「G.G.さんが酔っ払って呼びつけただけ」というオチまで含めて、無理のない運び。 |
| 構成・テンポ | 7.5 | シリアスな口論を、D.D.の深い独白→平手の破裂音で断ち切る緩急が見事。後半の風呂場とコーヒー牛乳の追いかけっこは少し長いが、前半の重さを抜くための配分として機能している。 |
| 文章・文体 | 7.0 | 「投擲──回避」の三連から「投擲──ごっ」に落とす記号の使い方は、この作品らしいリズムの生かし方。一方、ソプラノの一人称が「私」と「あたし」で揺れ、シエロの呼び方も「シエロさん」と「シエロちゃん」が場面ごとに混ざる（意図があるなら書き分けの基準を示したい）。 |
| 演出・見せ場 | 7.5 | 喧嘩の場面で、PO2たちが二人の足にしがみつき、さっちゃんがどちらに付くか迷ってオロオロ回る描写がコミカルで目に浮かぶ。AIを凌駕する回避能力が「無駄に仕事をしていた」というオチも冴えている。ただ「生えてないんだ」の下ネタは、読者を選ぶわりに笑いの効果が小さい。 |
| テーマ性 | 8.0 | D.D.の独白「こんな血みどろの銀河だから──『俺は空を飛べる』」は、飛ぶことと戦争の共犯関係を正面から見据えた、作品の核心に迫る一文。「平行線だね」「ええ、ずっとね」という和解の形も、答えを出さないまま共にいるというバディ／居場所のテーマを先取りしている。 |
| 引き・読後感 | 7.5 | 重い議論の後に大笑いのオチで締まり、後味が良い。D.D.の顔のあざが次の話に持ち越される小ネタも、連載の楽しみになっている。 |
| **総合** | **7.5**（平均7.4） | |

**良かった点**
- 倫理の衝突を「どちらも正しい」まま描き切り、D.D.の独白で作品のテーマの核心を言葉にしている。
- 平手→取っ組み合い→「喧嘩、ダメ」→二人で吹き出す、という感情の流れが自然。
- 風呂場の和解「平行線だね」は、短く印象に残る名やり取り。

**改善提案**
- ソプラノの一人称を「普段は"あたし"、取り繕うときは"私"」のように決めて統一する（第12話の「《あたし》／《私》」の対比が生きる）。
- 「生えてないんだ」のくだりは、「あたしの負けかな」→「尊厳の話よ」までで止めても十分笑える。削るか、一行に縮めたい。
- 平手の直前に、シエロがD.D.の横顔を見る一拍を入れると、「D.D.さんが、どんな想いで」へのつながりがより強くなる。

## 第11話「アンカー・ガレージ《ANCHOR GARAGE》」

**あらすじ**：喧嘩の後、ソプラノは黙ってD.D.を見送るようになり、やがて自分も操縦を習い始める。BH戦域での任務中、D.D.をおびき出し、通信をジャミングしたうえで、BHの賞金稼ぎ4機がセッティを襲う。シエロとPO2たちは被弾と火災に耐えながら持ちこたえ、ソプラノはブリッジで何もできない自分に涙する。伏兵を片付けたD.D.が駆けつけて4機を撃墜。その夜ソプラノは「戦うことそのものは悪ではない、でも殺してはいけない」と結論し、本名「ミース・クラヴェル」として自分の戦いに臨む決意を固める。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 8.0 | 指示を飛ばし続けて声を枯らし、最後に拳でコンソールを叩いて叫ぶシエロは、第二幕で最も輝く場面。戦後の「ホームポイントですから」→「それは、こちらの台詞です」の照れも、関係の深まりを自然に見せている。ソプラノが「怖いからじゃない。悔しいから」泣き、喧嘩と風呂の記憶から自分なりの不殺の思想にたどり着く流れには、成長の手応えがある。 |
| 世界観・設定 | 7.5 | 名が売れたエースを落とすには母艦を潰す、という賞金稼ぎの常套手段や、ブリッジの構造、PO2が分担して損害を抑える体制など、アンカー・ガレージの存在意義が具体的に描かれている。ただ、ミーさんが「居住班」を率いているなど、第一幕で決めた担当（ミーさん＝整備・機関）とずれている。 |
| ストーリー | 7.5 | 戦場での「違和感」→母艦襲撃→帰還、という流れは王道で、因果も明快。ただ、D.D.が伏兵に気づいていながら「手出ししてこないから、無視してた」と言うのは、違和感の伏線を自分で弱めている。結果的に、主人公の不注意がピンチを招いたようにも読めてしまう。 |

| 演出・見せ場 | 8.0 | 「おかえりなさいって言えないんじゃ──"アンカー"・ガレージじゃないんだから」の叫びと、PO2全員の『Pi！！！』の唱和は、幕題に直結する最大の見せ場。レーダー上の光点がふっと消える演出でD.D.の到着を知らせる手法も上手い。 |

| 引き・読後感 | 8.5 | 本名「ミース・クラヴェル」を、ナナさんのマイクも拾えないほどの小声でつぶやく締めは、余韻と次話への期待を両立している。 |
| **総合** | **7.9**（平均7.8） | |

- 何もできないソプラノの視点を通して籠城戦を描いたことで、恐怖と無力感が読者に直接伝わる。
- 戦闘後の温かい食卓から、「今まで自分がいた場所は"寒い場所"だった」と気づく流れ。

**改善提案**
- D.D.の「わかってた。手出ししてこないから、無視してた」は、「気配はあった。でも撃ってこないから……」くらいにとどめ、後で「見逃した」ことを悔やむ一行を足すと、主人公の判断ミスに見えにくくなる。
- 伏兵3機を片付ける場面を3〜5行入れ、「白銀の機体が煌めいた」から先、怒りのまま突き進むD.D.を見せると、到着のカタルシスが増す。
- PO2の担当を第一幕の設定に合わせる（居住班＝ユーさん、整備班＝ミーさん）。

## 第12話「ホームとアンカー《Home and anchor》」

**あらすじ**：セッティの修理中、ソプラノは「帰るね」と告げ、メモの連絡先をシエロに託す。シエロはG.G.の権限も使って、CCCの輸送船への極秘引き渡しを段取りする。最後の夜、ソプラノはナナさんにウサギのキーホルダーを贈り、シエロのアップルパイを食べながら涙する。引き渡しに向かう途中、CCCの正規軍クルセイダー6機が現れるが、D.D.は危険を承知で武装だけを破壊して退ける。ソプラノは「あたしにとってのホームポイントはセッティ、でも私のアンカーはここじゃない」と告げて去り、後日、ニュースで聖女ミース・クラヴェルとして民衆の前に復帰する。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 8.0 | 「家出を辞めたら人が死んだ」という筋書きを認められなかったD.D.の不殺を、シエロが言葉にされる前に察し、「ケーキはなしです」で許しと叱責を同時に済ませる。この流れで、二人の関係の成熟がよく分かる。天真爛漫な顔が「彫刻のような硬さ」に変わっていくソプラノも印象的。リーさんが燃え尽き、ナナさんが肩に手を置く結末まで、PO2たちの個性も立っている。 |
| 世界観・設定 | 7.0 | 死ぬために飛ぶような突撃をする正規軍「クルセイダー（C4）」は、宗教国家CCCの不気味さを一気に具体化した良い設定。D.D.がレクチャで予習していたという前振りもある。ただ、相手側が「ソプラノと名乗る少女の件で」の一言ですぐ察する場面は、正体を強く示しすぎている。 |
| ストーリー | 7.5 | 帰還の決意→準備→別れの夜→襲撃→不殺→別れ→正体判明、と別れの物語を一話で完結させた。ただ、引き渡しを嗅ぎつけたC4について、ソプラノの「怒りと諦め」の表情以外は誰も振り返らず、鋭いはずのシエロも黒幕を疑わないのは物足りない。アップルパイが「太鼓判を押した味」「一番好き」とされるが、それ以前に描かれていない。 |
| 構成・テンポ | 7.0 | 修理・レクチャ・段取り・贈り物・パイ・戦闘・別れ・後日談と、詰め込みが多い。特に冒頭の修理費のやり取りと宿舎の話は、もっと削れる。一方で、後日談のニュース場面の切り替えは鮮やか。 |
| 文章・文体 | 7.0 | 「｜高らか《soprano》に響く」のルビで偽名の由来を回収する遊び心は良い。ただ、「あの夜、シエロがセッティの全チャンネルに叫んだ言葉」としてホームポイントを挙げているが、全チャンネルで叫んだのは「アンカー・ガレージ」と「家」で、「ホームポイント」はD.D.との会話の言葉。不正確な振り返りになっている。 |
| 演出・見せ場 | 8.0 | 武装だけを撃ち抜いた後、六機の中央でただ佇むダンシング・ドールの「撃てるものなら、撃ってみろ」は、静けさで威圧する見事な絵。コーヒーを吹くD.D.、タブレットを落とすシエロ、燃え尽きるリーさんと、正体判明のコメディも連鎖して笑える。 |
| テーマ性 | 8.0 | 「ホーム（帰りたくなる場所）」と「アンカー（自分を繋ぎ止める場所）」は等号で結べない、という幕題の回答を、ソプラノの言葉で示した。傭兵にとっては一致する二つが、彼女にとっては分かれているという対比が、居場所のテーマに奥行きを与えている。 |
| 引き・読後感 | 8.0 | 別れのしんみりした余韻を、聖女判明の大笑いと、キーホルダーの「ちゃりちゃり」でまとめる読後感は上々。ソプラノとの再会への期待も自然に生まれる。 |
| **総合** | **7.7**（平均7.6） | |

**良かった点**
- 不殺の戦闘と、ダンシング・ドールが無言で佇む威圧の演出。D.D.の「わがまま」が技量の裏付けによって成立している。
- 「《あたし》のホームポイント／《私》のアンカー」という一人称の切り替えで、ソプラノの二面性と決意を一行で示している。
- 正体判明をシリアスではなくコメディとして処理し、リーさんの苦労まで回収した後日談。

**改善提案**
- アップルパイは第10話の風呂上がりか第11話の食卓で、ソプラノが一度食べて喜ぶ場面を入れておき、伏線として回収する。
- 「全チャンネルに叫んだ言葉」は「あの日、シエロが口にした言葉」などに直し、事実と合わせる。
- C4について、シエロに「引き渡しの情報が、どこから漏れたのか」と一行だけ疑わせ、未回収の引きとして残す。

## 第13話「ドール・マスター・トレイル（前編）《Doll Master trail -I-》」

**あらすじ**：日常に戻ったセッティに、ソプラノから暗号経由のメールが届く。同じ日、G.G.が愛機グラットン・グラビティで突然訪れ、「女を連れ込み、シエロの裸を見た」ことを口実にD.D.へ模擬戦を挑む。D.D.が着替えている間、シエロは先代人形遣い（D.M.）の存在を口にしかけたことを祖父に詫び、G.G.はD.M.に一度も勝てなかったことを明かす。模擬戦が始まると、D.D.は鉄壁のシールドと次々に出てくる兵装に追い詰められ、G.G.はついに切り札「グラットン・グラビティ・カノン」を展開する。

### 幕としての強み
- **幕題への明確な回答**：「ホーム（帰りたくなる場所）」と「アンカー（自分を繋ぎ止める場所）」を、ソプラノの別れの台詞で分けてみせた。セッティを守る籠城戦（第11話）でその前提を体感させてから、第12話で言葉にする二段構えが効いている。
- **シエロの多面化**：理知的なオペレーターに、嫉妬・激情・照れ・不器用な優しさが加わり、バディものとしての魅力が大きく上がった。
- **戦争と殺しをめぐる三者の立場の並置**：誰も論破されず、「平行線」のまま共に暮らす、という成熟した描き方。第12話の不殺の戦闘で、それが行動として結実する。
- **コメディの粒の良さ**：年齢騒動、さっちゃん投擲、聖女判明とリーさんの燃え尽き。PO2たちの集団芸が、作品の看板になりつつある。

### 幕としての課題と改善提案
1. **G.G.編（13〜14話）を幕題に結びつける**：今のままでは「ソプラノ編＋独立した模擬戦エピソード」に見える。シエロの任期満了の話を第13話の冒頭（ソプラノのメールを読む場面など）に前倒しし、「シエロにとってセッティはホームか、ただの職場か」を後半の縦糸にすると、第14話のガッツポーズが幕全体の締めとして機能する。
2. **ソプラノの正体の出し方を絞る**：「メッセンジャー」「教会で拾われ」「清らかな威厳」「CCC側が即座に察する」と手がかりが多く、読者は早い段階で聖女だと予想できる。どれかを削って謎として保つか、逆に読者にだけ早めに明かしてD.D.たちとの認識のずれを笑いにするか、方針をはっきりさせたい。
3. **D.D.の内面の変化を一場面で見せる**：第13話の冒頭で「有人機を撃墜した後は口数が減る」と要約で済ませている部分を、短い一場面（撃墜後のコクピットでの数行など）にすると、主人公の成長の線が見えやすくなる。
4. **C4襲撃の謎を引きとして残す**：引き渡し情報の漏れについてシエロに一言疑わせ、ソプラノとのメールに「こっちも色々あって」と匂わせるだけで、CCC内部の対立という次の幕への引きになる。
5. **設定と表記の整合性チェック**：PO2の担当（ユーさん／ミーさん）、ソプラノの一人称と呼び方、返済年数の計算、兵装の呼び方などを一覧にして、幕単位で推敲する。
