# 第三幕「流浪の悪魔」レビュー（第15〜22話）

## 第15話「騒がしくも前へ歩む日々よ《Loud and bright, the days go on》」

**あらすじ**：G.G.との約束から半年。D.D.とシエロは難度を上げたミッションを重ね、黒騎士V.S.とも何度か交戦するが決着はつかない。ソプラノとの暗号文通は続いており、彼女は一般船舶ライセンスを取ったと報告する一方、「止めてみせる」という一通も送ってくる。賞金首を落とした日の沈黙、ヴァンターの増加で口数が減るD.D.を励まそうと、シエロはルマスター家秘伝のブランデーケーキを焼くが、D.D.は泥酔してシエロに抱きつく。最後に口座残高が250億、目標の半分に届いたことが明かされる。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 7.0 | 賞金を得た日に「慣れなくても、いいと思いますよ」とだけ言い、それ以上踏み込まないシエロの距離の取り方は、第一幕の「かける言葉を持てなかった」彼女からの成長が見えて良い。泥酔したD.D.がさっちゃん・シエロに順に礼を言う場面は、普段口にしない感謝を出す仕掛けとして機能している。翌朝「……絶対に出しません」で締めるシエロの照れも可愛い。ただD.D.側の内面は「口数が減る」と外から書かれるだけで、何がどう重いのかは今回描かれない。 |
| 世界観・設定 | 6.0 | 「無人機奇襲→防衛戦→制宙権争奪戦」と難度が上がっていく流れや、ヴァンターの出現が増えたことは、名が売れた代償として筋が通っている。ソプラノが「一般船舶ライセンス」を取った話は日常の小ネタとして自然に置かれていて、後の伏線になる。ただ新しい設定の開示はほとんどなく、日常回としての役割を果たす程度。 |

| 構成・テンポ | 6.0 | 「例えば──」でV.S.、文通、沈黙のケーキ、秘伝ケーキ、残高と小話を並べる構成は読みやすい。ただ秘伝ケーキの段（スパナ→レンチ→ドリル）が分量の半分近くを占めていて、後半がやや間延びする。V.S.のモンタージュは逆に短すぎて重みが出ない。 |

| テーマ性 | 6.5 | 「殺した日にケーキを出す」行動がバディ／居場所のテーマを静かに支えている。ソプラノの「止めてみせる」というメールが、殺しを巡る対立がまだ続いていることを思い出させ、次話の「戦争を止めたい」への助走になっている。 |

**良かった点**
- ソプラノのライセンス取得やシエロの追伸「彼みたいな飛び方をしないで」を、日常の何気ない小ネタとして置いている（第21話で効いてくる）。
- 賞金を得た日の無言のケーキと秘伝ケーキの泥酔劇で、同じ「ケーキ」というモチーフを静と動の両方で使っている。
- PO2の個性（ミーさん＝整備脳、カナさん＝冷静な指摘役）がコメディの中で自然に立っている。

**改善提案**
- V.S.のモンタージュに、相手の台詞や互いの癖を一つ入れたい（例：すれ違いざまの『まだ生きてたか』）。因縁が育っていることを見せておけば、第21話の再登場がもっと重くなる。
- 秘伝ケーキの調理パートは、工具の天丼を2回程度に絞って3割ほど削る。その分を「口数が減る」D.D.の具体的な一場面（ログを眺めて手を止める、など）に回す。
- 「矢のように過ぎ去る」の冒頭は、「光陰矢の如し、とはよく言ったもので」のように素直な形にするか、具体的な時間経過の描写から入る方が締まる。

## 第16話「銀河の鳴動《Galactic tremor》」

**あらすじ**：250億という急ペースは、「人形遣い」の名に寄ってくる賞金稼ぎを返り討ちにするうちに膨らんだ雪だるま式の結果だった。折り返し地点で今後の方針を問われたD.D.は、「戦争を止めてみたい」と口にする。シエロは「無理に決まってる」と即答しつつ、方針を『劣勢戦局の介入・犠牲の抑止』と定める。その直後、ABFから報酬200億の指名依頼が届く。CCC前線最奥部「カテドラル・ライン」への侵攻の先導役で、戦力は異常に薄い。停戦への布石という一文を読み、D.D.は依頼を受けると決める。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 7.5 | 「無理に決まってるじゃないですか」と切り捨ててから「殺さないですむなら、殺さないほうがいい。──そういうことでしょう？」と拾い直すシエロの台詞は、このバディの関係を一番よく表した瞬間の一つ。D.D.の「……シエロさんは、笑う？」という頼りなさも人物像に合っている。事務口調は動揺している時の癖だ、とD.D.がもう知っているという描写で、1年半の積み重ねも見せている。 |
| 世界観・設定 | 6.5 | 賞金稼ぎを返り討ちにすると自分の賞金が上がり、さらに大物が寄ってくる、という「雪だるま式」の経済は説得力があって面白い。依頼書の「主力艦隊三個群、中身は旧式駆逐艦」という不自然さを読者にも提示しておく手つきも良い。ただ「艦隊司令の私的補足」が正式な依頼書に付記されているのはやや都合が良く、要件の読み上げが長い説明台詞になっている。 |
| ストーリー | 7.0 | 方針を決めた直後に、その方針を試すような依頼が来るという流れが綺麗。200億・侵攻・CCC（ソプラノの故郷）・停戦の布石と、迷う材料が段階的に積まれていく。依頼の異常さを読者に見せておきながら受けさせるので、次話の破綻の伏線にもなっている。 |
| 構成・テンポ | 6.5 | 前半（方針決め）と後半（指名依頼）の二部構成ははっきりしているが、どちらもキャビンでの会話劇なので、同じ場所・同じ調子が600行近く続く。依頼の分析パートは「異常です」「気になる記述があります」「もう一つ」と小出しを重ねるため、少しくどい。 |
| 文章・文体 | 7.0 | 「ズパッと」「うぐっ」などのくだけた擬音と、シリアスな地の文の切り替えは作品の味になっている。ラストの「半年前、『戦争を止めたい』なんて口にするとは思わなかった」は、今日口にしたばかりなので意味が取りにくい（「半年前の自分なら」のような補いが必要）。 |
| 演出・見せ場 | 6.0 | 会話劇の回なので見せ場は控えめ。真っ赤な緊急通知が和やかな空気を一瞬で断ち切る転換と、さっちゃんが膝に体を寄せて「ここにいる」と伝える一拍は、静かな演出としてよく利いている。 |
| テーマ性 | 8.0 | 「飛びたいだけ」の男が「戦争を止めたい」と口にする、主人公の動機が大きく転換する回。しかもそれを、ソプラノの故郷を攻めるという矛盾した依頼にすぐぶつけている。「戦争と殺し」の主題を、個人の覚悟から銀河規模の問いへ押し上げた。 |
| 引き・読後感 | 7.5 | 「俺が、その先頭を飛ぶ」という決意と、読者だけが感じている依頼の不穏さが重なり、次話を読みたくさせる。船の振動を子守唄に眠る締めは余韻があり、嵐の前の静けさとして機能している。 |
| **総合** | **7.0**（平均7.0） | |

**良かった点**
- 「無理に決まってる」と即答してから肯定し直す、シエロらしい支え方で主人公の動機を立てている。
- 依頼の異常さ（戦力の薄さ、報酬の高さ）を読者にも見せておき、次話の裏切りがフェアに伏線化されている。
- 方針（犠牲の抑止）と依頼（侵攻）のずれを、D.D.自身に「さっき言ったばかりなのに」と言わせている。

**改善提案**
- 依頼分析の小出し（「これは」「気になる記述」「もう一つ」）を2段階にまとめ、「停戦の布石」の一文を最後の決め手として際立たせる。
- 艦隊司令の「私的補足」は、依頼書の付記ではなく司令本人からの短い音声メッセージにすると、第17話の「全財産」告白とつながり、人物の顔が先に立つ。
- 「半年前、〜とは思わなかった」は「半年前の自分なら、『戦争を止めたい』なんて口にするとは思わなかっただろう」と補う。

## 第17話「戦場に讃美歌は響く《Choir on the battlefield》」

**あらすじ**：初めての侵攻戦。五隻の旧式艦隊の先頭を飛ぶD.D.は、CCCの対空格闘無人機152機をすべて引き受け、途中で「次元穿孔波動」の異常蓄積という珍しい現象を経験しつつ、被弾ゼロで全機を撃墜する。拠点は制圧され、艦隊司令は全財産だった200億を払った依頼に「戦死者ゼロ」と涙ながらに礼を言う。ところが後詰めが来ない。CCCの一個師団（攻撃機約1万）がワープアウトし、ABFは当該星域を放棄すると通達する。計画された敗北だったと悟り自分を責めるシエロを、D.D.はリーさんとミーさんに押さえさせ、一人で師団へ向かう。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 7.5 | 無人機相手に「（……気楽だな）」と思ってしまう後ろめたさと、「楽しい」と思う悪い癖。D.D.の危うさが素直に書けている。艦隊司令の「あの200億は、私の全財産に等しかった」は、一場面だけの人物を強く立たせた。シエロの「……オペレーター、失格です」からD.D.の「大丈夫だよ。俺は『人形遣い』なんだから」という虚勢までの流れで、守られる側だったD.D.が初めて守る側に回る。 |
| 世界観・設定 | 7.0 | 「来年度の戦費を通すための計画された敗北」という戦争経済の冷笑的な構造は、「数十世紀続く戦争」に具体的な理由の一端を与えていて良い。次元穿孔波動を本話で一度"予行"させ、「レクチャで習ったはず」とコメディで包んで設定を埋め込む手際も巧み。一方「主力艦隊三個群」の実態がわずか五隻というのは、前話の語と噛み合いが悪い。 |

| 文章・文体 | 7.0 | 「最適解を選ぶ相手は、最適解しか選ばない」「最適解の一歩外側を飛べばいい」など、能力を言語化する一文が冴えている。一方「シエロが、勢いよく振りかぶった」は語の誤用（振り向いた／かぶりを振った）。「D.D.は顔を伏せたまま」の直後に「顔を上げ」が続く部分は、動作の順序がやや混乱している。 |
| 演出・見せ場 | 8.0 | 球状包囲に対して「真ん中を抜ける」と密集地に飛び込み、敵の同士討ち回避で生まれた一瞬を突く。この機動は戦術の理屈が伝わる良いドッグファイト。艦隊の歓声が「怒号と、悲鳴と──それよりもずっと恐ろしい、沈黙」へ変わる音の演出も鮮烈。 |

**良かった点**
- 勝利の歓喜から裏切りへの反転が、前話の伏線（戦力の薄さ）を使ってフェアに組まれている。
- 艦隊司令という一場面だけの人物に「全財産」「部下が家に帰れる」という顔を与え、次話の殿の場面の感情を先に積んでいる。
- 次元穿孔波動をコメディで一度見せておき、次話のバーストを唐突に見せない工夫。

**改善提案**
- シエロの真相推理は「捨て石」→「戦費のための計画敗北」の2段に絞り、「……いえ」「そういうことだったのね」の重ねを削る。
- 前話の「主力艦隊三個群」との整合を取る（例：「三個群とは名ばかりの、わずか五隻」と本話で一言添える）。
- 「勢いよく振りかぶった」は「勢いよく振り向いた」または「激しくかぶりを振った」に直す。

## 第18話「流浪の悪魔《DRIFT DEMON》」

**あらすじ**：1万の群れに単機で挑むD.D.。中央突破の到達率3%という予測を受け、艦隊は外縁を迂回してゲートを目指し、D.D.は撹乱と阻止に回るが、味方は次々と落ちていく。艦隊司令は旗艦を反転させて殿を務め、「……すまない」と言い残して散る。二隻目も失われ、セッティに敵の手が届きかけたとき、至近距離での撃墜が重なり、ジェネレーターが暴走して「悪魔の暴走（デモンズ・バースト）」が発動する。300秒の臨界までに慣性を無視した機動と貫通弾で師団の95%を撃破し、残りを敗走させたD.D.は意識を失う。CCCの兵は彼を「悪魔」と叫んでいた。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 7.5 | 艦隊司令の殿（「君は、君にしかできないことを、してくれ」）と、それに対するD.D.の「なんで、あんたが謝るんだよ」。そして「名前も、聞いてなかったのに」の繰り返しは、D.D.の感性の柔らかさを最もよく表した場面。「戦術知識D、だもんなあ」と自分の作戦を素直に引っ込める姿も彼らしい。シエロは本話ではモニタを見る役に留まる。 |
| 世界観・設定 | 6.5 | バーストを「傭兵の与太話」として語らせ、「過去の実験では例外なく爆発」「生成フィールドを随時消費して均衡」というPO2の仮説を添える手順は丁寧。ただ1万機の95%を300秒で撃破し、戦艦のシールドまで貫くという規模は、作品のパワーバランスを一気に跳ね上げた。今後の緊張感が損なわれる懸念が残る。セッティ操舵の「RN854」は、既出のリーさんの識別番号と食い違っていないか確認したい。 |

**良かった点**
- 艦隊司令の殿と「名前も、聞いてなかった」で、逆転劇の前に喪失を置き、勝利に苦みを与えている。
- 「悪魔だ」を敵兵の悲鳴として言わせ、二つ名の誕生をドラマとして演出した。
- シールド表示や「慣性が、ない」など、ゲーム的な表示と体感描写を組み合わせて超常を伝えている。

**幕のあらすじ**：500億の折り返し地点で、D.D.は「戦争を止めてみたい」という願いを口にし、シエロと『劣勢戦局の介入・犠牲の抑止』を方針に定める。最初の大仕事、CCC前線最奥部への侵攻で戦死者ゼロの完全勝利を収めるが、それはABFが戦費のために仕組んだ捨て石作戦だった。放棄された艦隊を逃がすため、D.D.は単騎で一個師団に挑む。艦隊司令の殿を経て「悪魔の暴走」が発動し、師団の95%を壊滅させたことで、彼は「流浪の悪魔」と呼ばれるようになる。会見で罪悪感をめぐる問いを投げ返した彼の名は「悪魔の挑発」として広まり、5000年動かなかった戦線の支配率は52%に傾く。CCCは崩れ、大聖堂はBHに占拠され、亡命してきたソプラノは黒騎士の手でD.D.をかばって命を落とす。三枚の皿を前に泣いたD.D.は、彼女が望んだソラのために戦争を終わらせたいと願う。

### 幕としての強み
- **成功が悲劇を呼ぶ因果の連鎖**：戦死者ゼロの勝利→捨て石の露見→単騎での師団壊滅→二つ名→52%→大聖堂陥落→ソプラノの死。主人公の善意と戦果が、そのまま銀河の動乱と身近な喪失につながる設計が、タイトル「流浪の悪魔」の皮肉を物語として体現している。
- **作品固有の装置の回収**：〈生命反応：消失〉のログ、ケーキ（いい日だけ出る）、アップルパイ、ウサギのキーホルダー、「ホームとアンカー」。第一・二幕で積んだ小道具と言葉を、最も感情の高い場面で反転・再利用しており、シリーズ作品としての厚みを生んでいる。
- **バディの深化**：シエロが事務口調の裏の動揺をD.D.に見抜かれ、D.D.もシエロに見抜かれる、という相互理解が幕を通して描かれる。第22話の抱擁で、二人が「仕事の相棒」を超えた地点に達したことが言葉なしに示された。

### 幕としての課題と改善提案
1. **パワーインフレの抑制**：第18話で一万機の95%を撃破したことで、以降の戦闘の緊張感を保つのが難しくなった。バーストの代償（機体フレームの損傷、D.D.の身体への後遺症、再発すれば確実に死ぬという医学的・技術的な裏付け）を第19〜20話で明確に描き、「二度と使えない切り札」として封印しておくべき。
2. **因果の自覚を一手入れる**：D.D.の戦果が52%を生み、それが大聖堂陥落からソプラノの死へつながった、という幕最大の皮肉に、作中の誰も触れない。シエロだけが気づいて言えずにいる一行を第22話に入れれば、テーマが深まり、次幕への苦い伏線にもなる。
3. **ソプラノ退場の段取りの補強**：ルージュの事前の仕込み（文通での言及）、Aランク取得の過程の一端、待ち合わせ場所が漏れた経路の明示。この3点を補えば、第21話のご都合感が消え、悲劇の純度が上がる。
4. **V.S.の存在感の積み増し**：第15話のモンタージュで台詞や癖のやり取りを一つ入れる、第20話の大聖堂陥落の報にBHの英雄としてV.S.の名を出す、など。第21話で「聖女を殺した仇」になる人物の重みを、事前に積んでおきたい。
5. **説明独白の整理**：第17話のシエロの推理、第20話の懸念の二重語り、第22話の感情の要約と、同じ型の言い直しが幕全体で繰り返される。各回1箇所ずつ削るだけで、テンポが大きく改善する。
