# 第一幕「人形遣い」レビュー（第1〜8話）

## 第01話「スターティング・ガン《Before the unveiling》」

**あらすじ**：宇宙競艇の万年ビリレーサーだった青年は、進退をかけたレースで前の2機のクラッシュを避けるのが精一杯で最下位になり、無職になる。競艇場の外のベンチで途方に暮れていると、2mを超える老サイボーグに声をかけられ、「危険な職場」を紹介される。契約書を読み飛ばしてサインした瞬間、老人は伝説の傭兵G.G.だと名乗り、「お前は今日から傭兵だ」と告げる。青年は『D.D.』のコールサインを与えられ、のちに『流浪の悪魔』と呼ばれる男の誕生がナレーションで予告される。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 6.5 | 「僕がドンケツの、ドンガメです」と自分から言う卑屈さと、細かい字をSKIPしてサインする迂闊さで、主人公の人の好さが一言で伝わる。G.G.の「好都…いや、気の毒だ」の本音漏れも、胡散臭いのに憎めない老人として効いている。ただ主人公の内面は「飛び足りない」熱のひと段落だけで、まだ類型の域を出ていない。 |
| 世界観・設定 | 6.0 | 冒頭4行の「遥か遠い未来、あるいは我々とは違う世界」はスペオペの定番の入り方で、読者の構えは作りやすい。一方で「宇宙船の競艇」も「腕に内蔵されたプリンター」も一行で流れていき、この世界ならではの手触りはほとんどない。導入回として情報量を絞っているのは正しいが、独自性の芽をもう一つ見せたい。 |
| ストーリー | 6.5 | 「無職の日に、謎の老人と契約して傭兵になる」は掴みとして明快で、因果も短く通っている。ただ「契約書を読まずにサイン→実は傭兵契約」は既視感の強い型で、意外性は弱い。最終コーナーの回避という敗因が、後の話の伏線にもなっているのは良い。 |
| 構成・テンポ | 6.5 | 約150行と非常に短く、一気に読ませる。ただ前半の「〜だった」「無職」「なにもできない」と状況説明が続く段は要約的で、レースの場面そのものは2行しかない。導入の速さと引き換えに、場面が立ち上がる前に終わってしまう。 |
| 文章・文体 | 6.0 | 「そう、『だった』だ。」「まったくわかってない。」といった短いツッコミ地の文にはリズムがある。一方、「２メートル」の全角数字など表記が揃っておらず、一人称「僕」も3話以降の「俺」と揺れている（目上相手の使い分けなら一言あると親切）。説明的な一文一段落が続き、やや平板。 |
| 演出・見せ場 | 6.0 | 見せ場はG.G.の声に「凄み」が交じる反転と、名乗りの一連だけ。「暴食の重力」という二つ名はハッタリが効いているが、主人公が「じ、いじい……？？」と聞き違えるので緊張がすぐ笑いに崩れ、凄みとギャグのどちらも中途半端になっている。ラストの『｜流浪の悪魔《DRIFT DEMON》』の一行は格好いい。 |
| テーマ性 | 6.0 | 「飛ぶことが好き」「それが唯一の『財産』」と主題の種は置かれている。ただ戦争や殺しは冒頭の「戦火は燃え尽きず」の一行だけで、主人公とはまだ結びついていない。導入回なので点は抑えめにした。 |
| 引き・読後感 | 7.5 | 「──この銀河に、英雄は生まれていなかっただろう。」から『流浪の悪魔』の誕生予告で締める流れは王道で強く、続きを読ませる力は十分ある。ただし未来の二つ名を先に明かしたことで、「人形遣い」との関係が後々ややこしくなる（幕総評で後述）。 |
| **総合** | **6.5**（平均6.38） | |

**良かった点**
- 「ドンケツの、ドンガメ」が、のちのコールサイン「D.D.」の由来を匂わせる言葉遊びになっていて、説明せずに読者に気づかせている。
- 夜空を8隻のスプリントシップが弧を描く絵が、第8話のレース（8隻・8位）ときれいに対になっている。
- G.G.の「好都…いや」で、契約の胡散臭さをコメディとして先に見せている。

**改善提案**
- 最終コーナーのクラッシュを、要約ではなく3〜5行の実況にする（「目の前の2機が接触。」→機体の軌跡と、主人公の回避の一瞬を描く）。それが第2話の「死の危機での阿呆みてぇな機動」の初出になり、才能の伏線がずっと強くなる。
- 「じ、いじい……？？」の聞き違いギャグを削り、G.G.の名乗りを凄みのまま一拍置いてからD.D.の困惑に移る。そのほうが反転が効く。
- 「腕のプリンターから紙の契約書」のような、世界観の小ネタをもう一つ足し、SFの手触りを補強する。

## 第02話「リフト・ユニオン《Lift union》」

**あらすじ**：G.G.に連れられたD.D.は、道中で孫娘の愚痴を延々と聞かされたのち、区役所のような傭兵支援組織「リフト・ユニオン」本部に着く。適性テストを受けるが、筆記は戦術知識D・戦術判断Dと散々で、G.G.の孫娘シエロは「3日生き延びればいいほう」と呆れる。ところが実機演習で、D.D.は慣性で機体を横に滑らせる異様な機動を見せ、別人のような成績を出す。G.G.は「レースにゃ勝てねえが、戦場では誰も当てられねえ」と評し、シエロをD.D.専属オペレーターに任命する。結果は「SS」だった。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 7.0 | シエロが職務中は「G.G.役員」と呼び、動揺すると「おじいちゃん」「あたし」に戻るギャップが、一場面で彼女の性格と家族関係を伝えている。道中の「孫娘がつれない」愚痴が、そのままシエロの初登場に繋がるのも気が利いている。G.G.の「ワシがいままで役立たずをスカウトしたことがあったか？」の自負も好ましい。 |
| 世界観・設定 | 6.0 | 「独立自由傭兵支援組織」が「区役所」のような見た目、という外し方は良い。ただ「アンカー」「役員」など組織の仕組みは用語だけで、傭兵がどう仕事を受けて報酬を得るのかは見えない。テスト項目（一般常識C〜戦術判断D）は分かりやすい反面、SFらしさは薄い。 |
| ストーリー | 6.0 | 「座学は落第、実技は天才」は見慣れた型で、ほぼ予想通りに進む。G.G.の「飛ぶだけで満足してるような機動」という分析は、第8話で回収される良い伏線。ただこの話単体では、意外性の山がない。 |
| 構成・テンポ | 6.0 | 道中→筆記→別室→演習と場面は整理されているが、肝心の演習が4行（FIRE──命中／回避）しかなく、配分が説明側に寄っている。筆記試験の心の声が5つ並ぶ段は、テンポのための省略としては有効。 |
| 文章・文体 | 5.5 | 誤字と表記の揺れが目立つ。「付いたようだな」は「着いた」、「適正を調べる」は「適性」、「こじんまり」は「こぢんまり」、冒頭の「G.Gと名乗る」はピリオドの欠落。G.G.の「どこでも、同じだ。あれは、“ここ”でしか活かせねえ」は論旨が取りにくい（「どこでも同じ」と「ここでしか」が噛み合わない）。「そっかー、ただの愚痴だったかー」の句読点なしの地の文は、意図的なら良い味。 |
| 演出・見せ場 | 6.0 | 「──突如、D.D.の操縦する船が、横に滑る。」を見るシエロの驚き（「気持ち悪いぐらい──別人」）で才能を描く手法は正しい。ただ機動そのものの描写が少なく、読者がシエロと一緒に驚くには材料が足りない。「SS、ダブルスター」のオチは軽快。 |
| テーマ性 | 6.0 | 「あれは“ここ”でしか活かせねえ」が、本作の「居場所」のテーマの最初の一言。G.G.の言う「勝ちへの執念がない」も、「飛ぶこと」の主題に関わる性格づけとして置かれた。どちらも台詞での提示にとどまる。 |
| 引き・読後感 | 6.5 | 「SS」のオチは爽快で、シエロとのバディ結成への期待も生まれる。ただ「次に何が起きるか」の具体的なフックは弱い。 |
| **総合** | **6.2**（平均6.13） | |

**良かった点**
- 「孫娘がつれない」の愚痴が、数ページ後にシエロの初登場で回収される、小さな伏線の巧さ。
- シエロの公私の呼び分け（「G.G.役員」と「おじいちゃん」）で、説明なしに関係性を見せている。
- G.G.の「飛ぶだけで満足してる」という評が、第8話のレースで回収される長い伏線になっている。

**改善提案**
- 演習を10〜15行に増やす。仮想敵が回り込む→D.D.が慣性で滑りながら機首だけ振る→シエロの計器が「異常値」を示す、と、計器を通した描写を一段入れる。
- 「どこでも、同じだ。」を「レースじゃどこを飛んでも同じだ」などに直し、論理を通す。
- 誤字（付いた／適正／こじんまり／G.G）を修正する。

## 第03話「ダンシング・ドール《My trusty》」

**あらすじ**：書類手続きを終えたD.D.は、「人を殺せるのか」という不安を抱えたままドックへ向かい、シエロと正式に対面する。150mの小型母艦「アンカー・ガレージ」76K、通称セッティと、ユーさん・リーさん・ミーさんら102体の作業ロボットPO2を紹介され、白銀の戦闘機ダンシング・ドールとその戦術補助AI「さっちゃん」に出会う。扱いの難しい機体を気持ちよく乗りこなしたD.D.は、敬語禁止を言い渡されつつ、無人機ばかりの初仕事を受ける。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 6.5 | ドラム缶ロボ3台の登場（すかすか寄る／ゆっくり一度鳴く／壁にぶつかる）で、台詞なしに個性を描き分けたのは上手い。シエロの「さん付け」に眉が動いて諦めるくだりも、関係の距離感がよく出ている。D.D.は「船！自分が乗る船！！」と駆け出すはしゃぎぶりが可愛い反面、冒頭の「人を殺せるのか」の葛藤があっさり脇へ置かれている。 |
| 世界観・設定 | 7.0 | 「数十世紀続いている戦争ですから。人が戦ってる戦場のほうが少ないです」は、本作の世界観の核になる一行で、無人戦争という設定の独自性が光る。セッティ（76K＝セッテ・セイ）の命名遊びや、PO2が生活・母艦管制・整備を統括する分担も手触りがある。ただ第一幕の世界観開示はほぼこの話に集中していて、ABF（主人公側の陣営）の名前すら出ないのは惜しい。 |
| ストーリー | 6.0 | 母艦と愛機の受け取り、試験飛行、初任務の選定と、段取りを順にこなす回で、事件らしい事件はない。そのぶん、「使い古した跡の残るスティック」「本当に、あの船を、あの人に預けていいの？」と、機体の前の持ち主を匂わせる伏線を2つ置いたのは良い。 |
| 構成・テンポ | 6.0 | 紹介→移動→紹介→試験飛行→ブリーフィングと、紹介が続いて中盤がやや重い。試験飛行の「機体反応が敏感すぎる。」から始まる短い段落の連なりは、テンポが良い。ブリーフィングで、シエロの台詞が2つの鉤括弧に分かれて続いている箇所（「……数十世紀〜」「そういう場所は〜」）は、話者が分かりにくい。 |
| 文章・文体 | 5.5 | 「宇宙船ドッグ」「ドッグの傍ら」は「ドック」の誤り（第8話では「ドック」と書かれ、表記も揺れている）。「２０台前半」は「20代」、「ため息を付いた」は「ついた」。「シゴデキなキャリアウーマン」はWEB小説らしい軽さとして許容範囲。 |
| 演出・見せ場 | 6.0 | 愛機との対面（「うわ……」）から、さっちゃんのログ「＜操縦補助：介入不要＞」で静かに認められる流れは、ログ表示という本作の演出の型を確立した点で評価できる。ただ試験飛行の気持ちよさは「気持ちいいな、これ」の一言に頼っていて、飛ぶ快感の描写がもう一段ほしい。 |
| テーマ性 | 6.5 | 「……ホーム、か」「文字通りの“家”になりそうだった」で、居場所のテーマが明確に始まる。冒頭の「戦争して、人を殺すんだよな」も、第5〜6話への前振りとして機能している。 |

- PO2三台の登場を、台詞なしの動作だけで描き分けた点。のちの「ロボット群像」の基礎になっている。
- 「人が戦ってる戦場のほうが少ない」という設定。第4話の「無人だから楽」、第5話の「生命反応：消失」の衝撃まで、一本の線で繋がっている。
- 使い古されたスティックと、シエロの「あの船を、あの人に」の、さりげない伏線。

**改善提案**
- 冒頭の「人を殺せるのか」をブリーフィングで「人……殺さないとだめですか」と再び出しているので、冒頭のモノローグを削り、ブリーフィング一か所に集約すると重複が消える。
- 試験飛行で、機体の癖（推進ベクトルの偏り）を逆手に取る機動を1つ描く（例：わざとスピンを入れて機首だけ回す）。第4話の「横に滑る」の予告になる。
- 主人公が所属する陣営名（ABF）を、ブリーフィングの「隣国『バルバロス覇権機構』」と対で一行出しておく。

## 第04話「勝利と、失敗と、ケーキと《Sweet and bitter》」

**あらすじ**：初陣はバルバロス覇権機構の無人輸送船への襲撃。全部無人だと聞いて肩の力が抜けたD.D.は、さっちゃんの演算が追いつかない機動で、護衛の無人機56機をほぼ単機で殲滅する。だが夢中になっている間に、行儀の悪い傭兵「ヴァンター」に輸送船の積荷を横取りされてしまう。帰還したD.D.を、シエロは「楽しかったですか？」と叱りつつ、初陣祝いのショートケーキでねぎらう。その夜、さっちゃんの解析レポートを見たシエロは、G.G.がD.D.を連れてきた意味を理解し始める。

| 軸 | 点 | コメント |
|---|---|---|
| 人物 | 7.5 | 「楽しかったですか？」「…………はい」「でしょうね」の三往復で、D.D.の子供っぽさと、シエロの叱り方の上手さが同時に伝わる。叱った後に「ですが」で切り替えて、エースレベルと認めてケーキを出す流れで、シエロが単なる口うるさい役ではないと分かる。ケーキを恨めしそうに見るさっちゃんの『PuuuuuuPi……』も、キャラクターとして立った。 |
| 世界観・設定 | 7.0 | 「ヴァンター」（獲物を横取りする傭兵）という概念が、傭兵業界の生々しさを一発で伝える良い設定。「債務者」「利息がない」「撃墜されたら人生詰み」で、D.D.の経済的な立場も示された。ただ、何の債務か（機体の貸与費か、契約金か）がここで初めて出てきて、唐突に感じる。 |
| ストーリー | 7.0 | 「圧勝したのに任務は失敗」というひねりで、主人公の天才ぶりと未熟さを一度に描いたのは上手い。ヴァンターの横取りという外的要因で失敗させたことで、D.D.の弱点（目の前の飛行に没入する）が因果として通っている。 |
| 構成・テンポ | 7.0 | 出撃前の緊張→戦闘→横取り→説教とケーキ→夜の分析と、緩急の配分が良い。夜のシエロの場面で、本人の知らない場所での評価を見せる三人称の使い方も効果的。ケーキ後のさっちゃんの悲鳴「明日の朝までです」は、締めのギャグとして綺麗。 |
| 文章・文体 | 6.5 | FIREを字下げで縦に並べる表記（「FIRE。／一射。／撃墜。」）は、戦闘のリズムを視覚化していて効いている。一方、「ソファに腰を駆けると」は「掛けると」の誤り、「珈琲」と「コーヒー」が同じ場面で揺れている。「穏やかなシエロだった。その表情は、穏やかに見えて」と、「穏やか」が近くで重なっている。 |
| 演出・見せ場 | 7.5 | 「慣性に逆らわず、慣性を利用し、慣性に乗って──滑り、回り、撃つ。」は、主人公の戦い方を一文で言い切った名フレーズ。「＜回避不能＞」と判定された弾道の「ほんのわずかに外側」を掠めて飛ぶ描写で、AIの判定をD.D.が超える演出の型ができた。ただ56機を相手にした割に、敵の配置や位置関係はほとんど描かれず、絵としてはやや抽象的。 |
| テーマ性 | 6.5 | 「誰も、死なない。少しだけ、気が、楽だな」の安堵が、第5話の転落への前振りとして効いている。ケーキの「甘い。しばらくこんな甘いもの、食べてなかったな」で、居場所の温かさも始まった。テーマはまだ準備段階。 |
| 引き・読後感 | 7.0 | 満足感のある一話完結型の読後感。シエロの「おじいちゃんが連れてきた意味、少しわかった気がします」で、二人の関係の今後に期待が持てる。 |
| **総合** | **7.1**（平均7.00） | |

**良かった点**
- 「圧勝なのに任務失敗」の構造。主人公の才能と欠点を、一話で同時に提示した。

- 「慣性に逆らわず〜」の一文で、D.D.の戦闘スタイルが読者に刻まれる。

**改善提案**

- 誤字（腰を駆ける）を直し、珈琲／コーヒーの表記を統一する。

## 第05話「たった一行のログ《Silent line》」

**あらすじ**：シエロが選ぶ適度な難易度のミッションで、D.D.の傭兵生活は順調に回り始める。PO2の見分けがつかないD.D.のために、シエロは額にハートや魚のマークを描くという「対策」を講じ、ケーキのたびにさっちゃんがD.D.に体当たりしてくる日常が「家」になっていく。だがある日、軍部の情報もシエロの情報も外れ、D.D.は退避勧告を無視して敵母艦を撃破する。帰路、最後にしつこく食らいついてきた一機を撃ち落とした時、コンソールに「＜生命反応：消失＞」の一行が表示される。

### 幕としての強み
- **主題の同時進行と深化**：飛ぶこと・殺し・居場所・バディの四つの主題が、第3話から第8話まで途切れず絡み合い、第6〜7話で頂点に達する。G.G.の「代わりに誰かが人を殺してきた」と、黒騎士の「戦いに無縁の人間なんていねえ」が、同じ理屈の表と裏になっている構図は、作品の思想的な背骨として強い。
- **小道具と「ログ」の演出の発明**：ケーキの儀式（ご褒美→手つかず→メモ→スープ）で、台詞にしない感情を語る技術。さっちゃんの＜＞ログが、ギャグ（＜退避懇願＞）、緊張（＜シールド残量：3%＞）、衝撃（＜生命反応：消失＞）のすべてを担う、本作独自の表現装置になっている。
- **長距離の伏線回収**：第1話の敗因（クラッシュを避けた）→第2話のG.G.の評（勝ちへの執念がない）→第8話のレース（衝突が見えてしまう）と、主人公の才能と欠点が一つの答えに収束する設計が美しい。

### 幕としての課題と改善提案
1. **立ち上がりが遅い（第1〜3話）**：最初の実戦が第4話まで来ない。第1話の最終コーナーのクラッシュ回避を実況で描き、第2話の実機演習を10〜15行に厚くして、「飛ぶ快感と異能」を序盤のうちに体感させる。第3話の紹介パートは、PO2紹介をユー・リー・ミーの3台に絞り、「102体」は数字だけにとどめて圧縮する。
2. **勢力図の開示不足**：主人公の陣営ABFが第7話まで出てこず、略称が説明なしに並ぶ。第3話のブリーフィングで「ABF（我々の主な雇い主）とBH（バルバロス覇権機構）が数十世紀戦っている」を一文で示し、第7話の略称の初出に注釈を付ける。債務の中身（機体の貸与料など）も、第3話のサインの場面で一行仕込む。
3. **黒騎士戦の決着を主人公の手に**：撤退が外部の「作戦失敗」頼みなので、D.D.の防衛が敵の作戦失敗の一因になったことを、司令部ログか黒騎士の台詞（「てめえに足止めされてる間に、本隊が抜かれた」など）で示す。「勝てなかったが守り切った」という勝利条件を明確にすると、二つ名の誕生にも説得力が増す。
4. **二つ名の予告の整理**：第1話の「流浪の悪魔」と、第7話・第8話の「人形遣い」が並んで、未来の名前が二重になっている。第8話のラストを「人形遣い──それは、のちに銀河が別の名で呼ぶ男の、最初の名だった」のように第1話へ接続すれば、二つの名が段階として整理され、次の幕への期待にもなる。また第7話で命名まで描き切っているので、第8話の題「人形遣い」の回収が二度目になっている。第7話は「映像が広がった」までに抑え、命名はG.G.の口から初めて聞かせる構成も検討の余地がある。
5. **シエロの「見積もりミス」の繰り返しに意味を**：第4・5・6話と、シエロの見積もりミスと謝罪が3回続き、「シゴデキ」の第一印象と矛盾して見える。第2話の「単身サポートの経験がない」と明示的に結びつけ、第8話の分析で「自分も彼に合わせて学ぶ」と彼女の成長線を一行描けば、欠点が人物の弧に変わる。
